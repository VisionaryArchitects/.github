# Security Policy

## Reporting a vulnerability

Do not publish credentials, exploit details, private infrastructure information, or sensitive reproduction data in a public issue.

For a public repository, use **Security → Report a vulnerability** when private vulnerability reporting is available. For a private Visionary repository, report the problem through the existing private Visionary operator channel.

Include:

- The affected repository and version or commit.
- The security impact.
- Minimal reproduction steps.
- Any known workaround or proposed repair.

Security reports are investigated before public disclosure. A repository may define a more specific policy that overrides this default.
