# Visionary GitHub Defaults

This special public `.github` repository provides default community-health files for repositories owned by `VisionaryArchitects` when a repository does not define its own version.

It keeps contribution, issue, pull-request, support, conduct, and security guidance consistent without duplicating the same files across the portfolio.

Repository-specific files always take precedence over these defaults.

## Portfolio defaults

This repository supplies:

- a security policy, contribution guide, support guide, and code of conduct;
- structured bug and feature-request forms;
- a pull-request evidence checklist;
- ownership routing for this public defaults repository; and
- a least-privilege validation workflow for these governance files.

The repository intentionally contains no private infrastructure details, runtime state, or credentials. Product-specific build, test, deployment, and review requirements remain in each product repository.
