# Contributing to Visionary Projects

Thanks for helping improve a Visionary project.

## Before changing code

1. Read the repository README, `AGENTS.md`, and any scoped instructions.
2. Check existing issues and pull requests to avoid duplicating work.
3. Keep the change focused on one clear outcome.

## Pull requests

- Explain what changed and why.
- Include the commands and results used to validate the change.
- Identify meaningful risk and a rollback path.
- Keep failing or incomplete work in draft status.
- Never commit credentials, tokens, private keys, session data, local databases, build output, dependencies, or machine-specific configuration.

Repository-specific instructions override this default guide.
